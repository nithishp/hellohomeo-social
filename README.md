# hellohomeo-social

Public image host and content log for the HelloHomeo Instagram carousels (@hellohomeo.in).

- `posts/YYYY-MM-DD-topic-slug/` holds the rendered slides (01.png, 02.png, …) and a contact sheet. Buffer pulls the slides from their raw GitHub links when it creates each draft.
- `log.md` records every carousel made, so the weekly run never repeats a topic and rotates formats.

Everything here is generated by the weekly scheduled task. Brand colors, fonts and logos come from the HelloHomeo website repo, which is never modified.
