# Style guide — 2026-W45 "Repertory to prescription"
- Canvas 1080×1920, 30 fps. Surfaces: ink #070C1F (primary), #0A0B0E (deep), ink text #0B1220 on UI cards.
- Accent jade #10B880; deep jade #06805A for text on light; on-dark accent #5FD6AC; tint #E8F8F1; card border #CDEFE0.
- Type: Inter 800 display (tight −2px tracking, 88–120 px for kinetic lines); Poppins 400/500/600 for UI and captions (≥ 34 px on canvas).
- UI cards: white, radius 28–32 px, shadow 0 40px 80px -45px rgba(8,58,44,.45) (green-tinted, from design.md).
- Readable at 360 px wide: no on-canvas text under 34 px except UI-internal labels that are decorative proof.
- Real people only from Higgsfield documentary clinic shots; never presented as users, no testimonials.
- Banned: zooming/Ken Burns on screenshots, image-to-video on UI, blob gradients, glitch, logo stings, fade from black.
