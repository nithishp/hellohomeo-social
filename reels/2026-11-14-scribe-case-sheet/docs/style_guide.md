# Style guide — 2026-W46 "The case sheet writes itself" (Scribe AI)
- Canvas 1080×1920, 30 fps. Surfaces: ink #070C1F; UI text ink #0B1220.
- Accent jade #10B880; deep jade #06805A for text on light; on-dark accent #5FD6AC; tint #E8F8F1; card border #CDEFE0. (Confirmed in nithishp/hellohomeo design.md "Colour" section.)
- Type: Inter 800 display (−2.5 px tracking, 88 px heads, 104 px kinetic lines); Poppins 400/500/600 for UI and captions; Noto Sans Devanagari for the Hindi transcript (the app renders Hindi with a system Devanagari font).
- UI cards: white, radius 32, shadow 0 40px 80px -45px rgba(8,58,44,.45) (green-tinted, design.md).
- Depth: dot grid (16 px/s, loops exactly in 30 s) + a faint jade "ghost card" drifting behind the foreground card.
- Readable at 360 px: UI values ≥ 38 px, captions 40 px.
- People: only Higgsfield documentary clinic shots (one doctor, same face in A and B2). Never presented as a user; no testimonial.
- Banned: zooming/Ken Burns on screenshots, image-to-video on UI, blob gradients, glitch, logo stings, fade from black.
