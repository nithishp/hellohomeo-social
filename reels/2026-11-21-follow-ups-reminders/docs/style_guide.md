# Style guide — 2026-W47 "Follow-ups that book themselves"
- Surfaces: ink #070C1F (base), dot grid rgba(95,214,172,.10), ghost card. No blob gradients.
- Accent: jade #10B880 (logo #10b981); deep jade #06805A for text on light; tint #E8F8F1; light jade on dark #5FD6AC. Ink text #0B1220. Muted #6A7385.
- Type: Inter 800 display (88–110 px, -2.5 px tracking); Poppins 400/500/600 body (≥36 px on UI values, captions 40 px). Readable at 360 px wide.
- UI cards: white, radius 32 px, green-tinted shadow `0 40px 80px -45px rgba(8,58,44,.45)` + 2 px jade ring (design.md radius/shadow language).
- Chat bubbles: neutral chat styling (no WhatsApp logo or trademark styling); bot bubbles white, patient bubbles tint #DCF5E9.
- Motion: quint-out entries (0.5–0.6 s), back-out for pops, cubic-in exits (0.25–0.35 s). One push-in max per shot. Cuts on the music grid (106.7 BPM, beat 0.5625 s).
- Banned: screenshot zooms/Ken Burns, i2v on app screens, glitch, logo sting, fade from black.
