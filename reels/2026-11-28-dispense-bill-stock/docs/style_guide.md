# Style guide — 2026-W48 "Dispense once. Stock updates." (billing & inventory)
- Surfaces: ink #070C1F with a faint jade dot grid (rgba(95,214,172,.10)); white UI cards, radius 32, soft green-tinted shadow + 2px jade ring (design.md tokens).
- Accent: jade #10B880 (headline line 2, buttons, ticks); deep jade #06805A for green text on white; jade-on-dark #5FD6AC; amber #D97706/#B45309 only for "pending"/"low stock" states (as the app uses).
- Type: Inter 800, 92 px headlines, tight (-2.5 px); kinetic lines Inter 800 104 px. Poppins 400–600 for UI text, ≥ 30 px inside cards (readable at 360 px wide).
- Motion: cards glide up 70–140 px and snap (quint out, 0.5 s); alerts pop with a light overshoot (back out); state changes are instant swaps (tick, pill, number roll). One gentle push-in max per shot. No zooms on screenshots, no glitch, no gradients blobs, no fade from black.
- People/places: only Higgsfield documentary shots (Indian homeopathy dispensary, warm light). No app screens in generated video.
- Patient shown on rebuilt UI: fictional "Kavya Menon"; doctor "Dr. Demo". Demo stock values (Arnica Montana 30C) mirror the seeded demo clinic.
